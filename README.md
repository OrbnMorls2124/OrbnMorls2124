## Featured Projects

### Smart Waste Detector

Real-time computer vision app that uses the webcam to classify objects and group them into recycling categories (plastic, glass, paper, metal, organic, electronic, and more).

Built with Python, OpenCV DNN, and a MobileNetV2 ONNX model. It includes a Tkinter interface, detection stabilization with a 12-frame voting buffer and hysteresis, double buffering, and asynchronous capture/inference.
