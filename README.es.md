## Proyectos destacados

### Detector de Residuos Inteligente

Aplicación de visión por computadora que usa la webcam para clasificar objetos en tiempo real y agruparlos en categorías de reciclaje (plástico, vidrio, papel, metal, orgánico, electrónico, entre otras).

Hecha con Python, el módulo DNN de OpenCV y un modelo MobileNetV2 en formato ONNX. Incluye interfaz en Tkinter, estabilización de detecciones con un buffer de votación de 12 frames e histéresis, doble buffer y procesamiento asíncrono entre captura e inferencia.

https://github.com/OrbnMorls2124/Proyecto-Analisis-de-Algoritmos-

### Sistema de Facturación e Inventario

Backend para facturación, clientes, inventario, productos, reportes y gestión de usuarios, desarrollado con Python y Django.

Incluye documentación de la API, soporte para Docker y checklist de producción.

https://github.com/OrbnMorls2124/Proyectos-Personales/tree/main/Sistema%20Facturacion%20e%20Inventario

### Nova Commerce
